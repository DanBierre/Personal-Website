# Security

This is a static personal site: plain HTML, CSS and JavaScript, no server, no forms, no cookies, no tracking.

- A Content-Security-Policy in `index.html` only allows the site's own files and Google Fonts.
- No secrets, keys or private files belong in this repo (see `.gitignore`).

## Reporting a problem

Found something? Please email bierredan@gmail.com rather than opening a public issue.
